## 🎯 Overview

**Monotonic Stack** is a stack that maintains elements in monotonic (increasing or decreasing) order. It's a powerful technique for solving problems involving next greater/smaller elements.

## 🎓 Learning Objectives

- Understand monotonic stack patterns
- Solve next greater/smaller element problems
- Apply to histogram and temperature problems
- Master O(n) solutions for array problems

## 💻 Problems

### Problem 1: Next Greater Element
Find next greater element for each element in array.

### Problem 2: Largest Rectangle in Histogram
Find largest rectangular area in histogram.

### Problem 3: Daily Temperatures
Calculate days until warmer temperature.

### Problem 4: Stock Span
Calculate stock span for each day.

**Complexity:** All problems O(n) time, O(n) space
