# ==============================================================================
# Version Pinning Strategy
# ==============================================================================
# - Major versions capped to prevent breaking changes
# - Minor versions allowed to float for bug fixes
# - Use `pip freeze > requirements-lock.txt` for exact reproducibility
# - CI should use requirements-lock.txt, devs can use requirements-dev.txt

# ==============================================================================
# Installation Instructions
# ==============================================================================
# 1. Create virtual environment:
#    python3.12 -m venv venv
#    source venv/bin/activate  # On Windows: venv\Scripts\activate
#
# 2. Upgrade pip:
#    pip install --upgrade pip setuptools wheel
#
# 3. Install dependencies:
#    pip install -r requirements-dev.txt
#
# 4. Verify installation:
#    python -c "import torch; print(torch.__version__)"
#    python -c "import numpy; print(numpy.__version__)"
#    pytest --version
#
# 5. (Optional) Install in editable mode:
#    pip install -e .

# ==============================================================================
# Notes
# ==============================================================================
